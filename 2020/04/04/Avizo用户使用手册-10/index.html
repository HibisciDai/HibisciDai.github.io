10 用户界面组件、一般概念、启动

本章包含对Avizo界面组件、数据类型、一般概念以及启动选项的说明。理解以下各节并不需要对Avizo有深入的了解，但最好先看一下第1.7章（Avizo中的第一步）中所包含的某个教程，特别是第2节（入门）中所描述的第一个教程。

10.1 用户界面组件

本节描述以下界面组件：

  • File Menu文件菜单、Edit Menu编辑菜单、Project Menu项目菜单、View Menu视图菜单、Window Menu窗口菜单、Help Menu帮助菜单
  • Standard Toolbar标准工具栏、Workrooms Toolbar工作间工具栏
  • Project View项目视图、Properties Area属性区域、Progress Bar进度条、Viewer Window查看器窗口、Console Window控制台窗口、Online Help在线帮助、Histogram Panel直方图面板、Correlation Panel相关性面板
  • File Dialog文件对话框、Job Dialog作业对话框、Preferences Dialog首选项对话框、Snapshot Dialog快照对话框、System Information系统信息
  • Object Popup对象弹出菜单、Create Object Popup创建对象弹出菜单

10.1.1 文件菜单

文件菜单让你能够加载和保存数据对象以及Avizo项目脚本。此外，它还让你访问最近使用的文件和项目，并允许你退出程序。在下文中，各个菜单条目将被分别讨论。

10.1.1.1 Open Data

Open Data按钮会激活Avizo的文件对话框，让你导入存储在文件中的数据集。Avizo所支持的大多数文件格式，都可以通过文件头或文件名扩展名自动识别。如果你试图加载一个无法自动检测出格式的文件，就会弹出一个额外的对话框，要求你手动选择格式。

所支持文件格式的完整列表包含在参考手册中。关于如何导入你自己数据的提示，见第2.6节。

如果你在文件对话框中选择多个文件，只要它们全部以相同格式存储，就都会被加载。存储在不同文件中的2D图像通常会被合并为单个3D数据对象。另一方面，也有一些文件格式会创建多个数据对象。最后，你还可以使用Open按钮导入并执行Avizo项目脚本。

10.1.1.2 Open Data As

输入数据的格式可以使用Open Data As来强制指定。系统会打开一个格式选择对话框，允许你在所有受支持的Avizo文件格式中进行选择。所有被选中的文件都将被当作指定格式来处理。

10.1.1.3 Open Time Series Data

该按钮同样会激活文件对话框，但与普通的Open选项不同，它假定所有被选中的文件代表单个数据对象的不同时间步。当加载这样一个时间序列时，系统会创建一个Time Series Control模块的实例。该模块提供一个时间滑块，允许你调整当前时间步。每当选择一个新的时间步时，相应的数据文件就会被读取，与前一个时间步关联的数据对象则被替换。该模块还提供一个缓存，只要缓存足够大，数据文件就只需被读取一次。

10.1.1.4 Open Time Series Data As

该菜单条目的工作方式与Open Time Series Data相同，只是输入数据的格式可以被强制指定（与Open Data As相同）。系统会打开一个格式选择对话框，允许你在所有受支持的Avizo文件格式中进行选择。所有被选中的文件都将被当作指定格式来处理。

10.1.1.5 Save Data

Save Data按钮允许你以原生Avizo文件格式(.am)保存单个被修改过的数据对象。如果最初加载的数据是一个Avizo文件，那么只有在待保存的数据对象被选中、并且该数据对象已被修改过（裁剪、变换等）时，保存按钮才会处于可用状态。重要提示：在这种情况下，原始的Avizo文件格式会被新的修改后数据覆盖，且不再另行通知。如果最初加载的数据来自另一种文件格式(TIFF等)，那么只有在待保存的数据对象被选中时，保存按钮才会可用。保存时，应用程序会要求把该文件保存为原生Avizo文件格式。此后对已保存为Avizo文件的数据进行的任何保存，都会覆盖磁盘上被修改的数据，且不再另行通知。Save按钮的一个常见用途，是在Avizo的Segmentation Editor中进行手动分割期间存储中间结果。

10.1.1.6 Save Data As

该按钮允许你把一个数据对象写入一个采用原生文件格式的文件中。为此，你必须先选择该数据对象（单击相应的绿色数据图标）。然后选择Save Data As以激活Avizo的文件对话框。该文件对话框会呈现出适合保存该数据对象的所有原生文件格式的列表。选择你喜欢的那个并按OK。请注意，你必须指定包含后缀在内的完整文件名。Avizo不会自动向文件名添加后缀。不过，每当你从文件格式列表中选择一种新格式时，Avizo会更新该后缀。此外，在覆盖已有文件之前，Avizo会先询问你。

如果对于某种类型的数据对象根本没有注册任何原生文件格式，Save Data As按钮就会被禁用。如果在项目视图中选中了多个数据对象，它同样会被禁用。

原生文件格式是指能够保存Avizo中所有数据属性的文件格式。实际上，只有两种原生文件格式：Avizo Data Format和HxSurface。

10.1.1.7 Export Data As

该按钮所做的事情与Save Data As按钮相同，不过文件对话框会呈现出适合保存该数据对象的所有文件格式的列表，无论是否为原生格式。

有些文件格式会为单个数据对象创建多个文件。例如，一个3D图像数据集的每个切片都可能被保存为一个单独的光栅文件。在这种情况下，你可以在文件名中加入一串井号（例如<filename>####.jpg）。这个序列会被替换为带前导零的连续数字。

如果对于某种类型的数据对象根本没有注册任何文件格式，Export Data As按钮就会被禁用。如果在项目视图中选中了多个数据对象，它同样会被禁用。

10.1.1.8 Convert to Large Data Format

当选择该菜单条目时，一个Convert to Large Data Format对象会被实例化并添加到项目视图中。该模块允许你把大型图像数据转换为LDA文件格式。

10.1.1.9 New Project

该按钮执行一次Remove all objects，以便你可以在项目视图中开始构建一个新项目。它还会把新的项目名称设为”Untitled.hx”。

10.1.1.10 Open Project

Open Project按钮会激活Avizo的文件对话框，让你加载存储在文件中的项目。项目文件在对话框中显示为”Avizo Project”格式。在加载新项目之前会先执行一次Remove all objects，以便新项目有效地替换项目视图中的旧项目。目前只能打开扩展名为.hx的文件。

10.1.1.11 Save Project

该按钮允许你保存项目视图中所显示的完整图标与连接的项目。在Avizo中第一次保存项目时，会显示一个”保存项目策略”对话框（见图10.1）。该对话框建议了不同的策略，并对每种策略给出简短说明。关于这些选项的更多细节可以在General Tab一节中找到。所选择的策略将仅应用于正在保存的这个项目，除非勾选了该复选框。如果勾选了该复选框，那么应用于正在保存项目的策略将适用于所有未来的项目。这项设置之后可以在首选项对话框的General Tab中修改。

图 10.1：保存项目策略对话框。

如果该项目此前未被保存过，你需要在文件对话框中指定一个Avizo项目脚本的名称。当执行该脚本时，它会恢复所有数据对象和模块，以及当前的对象变换和相机设置。这个特性对于从你上次中断的地方继续工作很有用。

请注意，通常所有数据对象都必须已被存储在某个文件中，才能保存该项目。如果情况并非如此，系统会显示一个对话框，列出所有仍需被保存的数据对象。在该对话框中，你可以指定所有必需的数据对象都应被自动保存到一个单独的子目录中。

除了选择Avizo Project选项之外，你也可以从文件对话框的格式菜单中选择Avizo Project and data files (pack & go)。在这种情况下，当前加载的所有数据对象都会被保存到一个单独的目录中。影响项目脚本导出的更多选项，可以在首选项对话框中调整。

10.1.1.12 Save Project As

该按钮的工作方式与Save Project按钮相同，只是在这种情况下，你总是需要在文件对话框中指定一个Avizo项目脚本的名称。

10.1.1.13 Save Project As Template

该按钮允许你把当前的项目视图保存为一个模板项目。模板项目由一个原始项目的备份构成，它可以被复制应用到同类型的其他数据上。参见第11.1.1节 模板项目说明。

10.1.1.14 Recent Files

该按钮可用于加载最近使用过的文件。当选择该菜单条目时，会出现一个子菜单，列出最近的五个文件。如果加载过多个2D图像，则会用第一个文件的名称后跟省略号(…)来指示。最近文件列表中所显示文件的数量，可以在首选项对话框的General标签页中修改。

10.1.1.15 Recent Projects

该按钮可用于加载最近使用过的项目脚本。当选择该菜单条目时，会出现一个子菜单，列出最近的五个项目脚本。最近项目列表中所显示项目的数量，可以在首选项对话框的General标签页中修改。

10.1.1.16 Quit

该按钮终止Avizo；如果存在未保存的更改，它会提示你保存当前的项目配置。

10.1.2 编辑菜单

Edit菜单提供对标准剪切/复制/粘贴/删除命令的访问，也提供对Avizo各对话框的访问：首选项对话框、作业对话框以及参数编辑器的扩展版本。

10.1.2.1 Cut

在Console中，该命令剪切选中的文本并把它复制到剪贴板。在Project View中，该命令移除选中的对象。

10.1.2.2 Copy

在Console中，该命令把选中的文本复制到剪贴板。在Project View中，该命令复制选中的对象。

10.1.2.3 Paste

在Console中，该命令把剪贴板中的文本粘贴到当前文本插入点。在Project View中，该命令创建被剪切或复制的对象。

10.1.2.4 Delete

在Console中，该命令删除选中的文本。在Project View中，该命令删除选中的对象。

10.1.2.5 Select All

在Console中，该命令选中所有文本。在Project View中，该命令选中所有对象。

10.1.2.6 Preferences

该选项打开Avizo的首选项对话框。该对话框允许你调整Avizo的某些全局设置，例如项目视图选项、用户界面布局、项目脚本的导出方式、分割、渲染和性能选项等。

10.1.2.7 Dialogs

该菜单项包含Database和Jobs两个对话框。

Database

Database按钮会激活数据参数编辑器的一个扩展版本，允许你操作Avizo的全局参数数据库。除其他内容外，该参数数据库包含一组预定义的材料（用于图像分割和曲面重建）以及一组预定义的边界id（用于曲面编辑和FEM前处理）。例如，可以在数据库中为每种材料和每个边界id定义一种默认颜色。

参数的修改、插入和移除，与在普通参数编辑器中的做法相同。此外，扩展的参数对话框还提供一个菜单栏，允许你加载、导入、保存或搜索全局参数数据库。Avizo的默认数据库存储在Avizo安装目录下的文件share/materials/database_avizo.hm中。使用Database菜单选项Set default file可以指定改用另一个数据库文件。该更改是永久性的，即在Avizo重启后仍然生效。要切换回系统默认设置，请使用Database菜单选项Use system default file。

Jobs

该按钮调出Avizo的作业对话框，用于控制在后台运行的批处理作业的执行。例如，四面体网格可以在一个批处理作业中生成（参见模块Generate Tetra Grid）。不过，对大多数用户而言，批处理队列的意义不大。

10.1.3.4 Remove Object

Remove Object按钮删除所有选中的对象，并从项目视图中移除相应的图标。按Delete键可以得到同样的效果。如果你之后还想重用某个数据对象，请务必在删除它之前把它保存到文件中。如果某个数据对象已被修改但尚未保存到文件，它会在对象图标中以一个小星号标记。在首选项对话框中，你可以选择：当你试图删除那些无法由上游计算模块重新计算的未保存数据对象时，是否应打印一个警告对话框。如果你删除一个数据对象，所有相连的模块也会被一并删除。不过，如果你删除一个模块，相连的数据对象（例如某个计算模块的结果）会被保留。

10.1.4.1 Layout

Layout按钮让你在一个、两个或四个3D查看器之间进行选择。所有查看器都会以默认布局放置在一个公共窗口内。如果你想在一个单独的窗口中创建一个额外的查看器，请选择Extra Viewer。你甚至可以使用Tcl命令viewer <n> show创建更多的查看器。从n=4开始，查看器将被放置在单独的窗口中。

10.1.4.2 Background

Background按钮打开背景对话框，允许你在uniform（均匀）和gradient（渐变）背景风格之间切换。此外，该对话框还允许你调整这些风格所使用的两种颜色。请注意，checkerboard（棋盘格）风格已被弃用。

10.1.4.3 Transparency

Transparency按钮控制在渲染过程中相对于对象透明度计算像素值的方式。

  • Screen Door：透明曲面用点画图案(stipple pattern)来近似。
  • Add：加性alpha混合。
  • Add Delayed：带两遍渲染的加性alpha混合。不透明对象先渲染，透明对象后渲染。
  • Add Sorted：与Add Delayed类似，但透明对象会按边界框中心到相机的距离排序，并以从后到前的顺序渲染。
  • Blend：乘性alpha混合。
  • Blend Delayed：带两遍渲染的乘性alpha混合。不透明对象先渲染，透明对象后渲染。
  • Blend Sorted：与Blend Delayed类似，但透明对象会按边界框中心到相机的距离排序，并以从后到前的顺序渲染。
  • Sorted Layers：使用一种片元级深度排序技术，对复杂的透明对象能给出更好的结果。你的显卡必须支持Multi-Texture、Texture Environment Combine、Depth texture和Shadow这些OpenGL扩展。如果显卡不支持这些扩展，其行为将如同设置了Blend Sorted。
  • Sorted Layers Delayed：与Sorted Layers类似，但会在不透明对象之后渲染所有透明对象。

注意：Sorted Layers和Sorted Layers Delayed模式不支持抗锯齿。

10.1.4.4 Lights

Lights菜单让你为3D查看器激活不同的光照设置。默认情况下，查看器使用单个头灯(headlight)，即一个方向光，其照射方向几乎与相机的观察方向相同。可以通过查看器的弹出菜单在每个查看器中开启或关闭该头灯。此外，也可以使用这个Lights菜单中的头灯开关，为所有查看器开启或关闭头灯。可以使用Standard按钮恢复这套标准光照设置。通过在$AVIZO_ROOT/share/lights中创建适当的文件，可以定义更多的光照设置。

在任何时候，都可以通过Create light选项创建额外的光源。除查看器的默认头灯之外，所有光源在项目视图中都用蓝色的小图标表示，就像普通的数据对象或模块一样。为了让所有被隐藏的光源图标变为可见，请使用Show all icons选项。Hide all icons则隐藏所有光源对象的图标。关于光源的更多信息，请参阅本手册的参考部分。

10.1.4.5 Fog

Fog按钮为所显示的场景引入雾效果，并控制不透明度如何随与相机的距离而增加。雾效果只能在uniform背景上看到。fogRange查看器命令提供了更精细的调节。

  • None：无雾效果（默认）。
  • Haze：不透明度随距离线性增加。
  • Fog：不透明度随距离指数增加。
  • Smoke：不透明度随距离按指数平方增加。

10.1.4.6 Antialiasing

Antialiasing...按钮打开一个对话框，通过它可以修改所有活动查看器的抗锯齿质量值。抗锯齿是通过使用中间色调来平滑图形图像上锯齿状边缘的过程。

该对话框提供了几个不同的界面组件：一个可勾选的分组框、一个质量滑块和三个按钮。

可勾选的分组框允许你为所有查看器开启或关闭抗锯齿。滑块和相应的文本字段让你设置抗锯齿质量，取值范围从0到1，1为最佳。这些按钮用于应用、保存或重置更改以及退出对话框。以下给出各界面组件的详细说明。

Antialiasing分组框：该分组框由一个滑块和一个复选框组成。当被勾选时，将以给定的质量值应用抗锯齿。否则，抗锯齿被禁用。

Quality滑块：抗锯齿质量滑块呈现质量取值范围。如果滑块值发生变化，就会应用相应的抗锯齿。该滑块伴有一个文本编辑字段，用于查看当前抗锯齿的精确值并设置其数值。这些组件的值始终在0到1的范围内。

抗锯齿可以通过两种不同的方式完成。如果通过ARB_multisample和ARB_pixel_format这两个OpenGL扩展支持全场景抗锯齿，则使用它进行渲染。请注意，抗锯齿计算中所使用的采样数取决于你的图形硬件和视频驱动程序。NVidia图形硬件可以支持”采样数 * 2”个质量级别（前提是NV_multisample_filter_hint这个OpenGL扩展可用）。如果不支持，则改用平滑和多遍(multipass)抗锯齿。

按钮：名为OK、Save和Cancel的这三个按钮分别用于：关闭对话框并把更改应用到抗锯齿(OK)、把状态和质量保存到首选项中(Save)，以及不应用更改就关闭对话框(Cancel)。

注意：Sorted Layers和Sorted Layers Delayed透明度模式不支持抗锯齿。

10.1.9.1 项目图视图

概念

如果选择了Graph View，就会显示Project Graph View。这个选择是通过单击Project Menu中的Graph View按钮来完成的。

一旦某个数据对象被加载或某个模块被创建，它就会在Project Graph View中由一个图标表示。有些对象——特别是初始加载的颜色图——在这里可能不可见。此类被隐藏的对象列在Avizo主窗口的Project > Show Object菜单中。从该菜单中选择一个对象，会使相应的图标在Project Graph View中变为可见。

图标颜色用于指示不同类型的对象。数据对象显示为绿色，它们是唯一可以使用File > Save Data、File > Save Data As或File > Export Data As菜单项保存到磁盘的对象。计算模块显示为红色，可视化模块为黄色，而切片(slicing)类型的可视化模块为橙色。这些模块（例如Ortho Slice）可用于裁剪任何其他模块的图形输出。

数据对象与处理模块之间的连接显示为蓝线，代表数据的流向。对于显示模块，这些连接展示了用于生成该显示的数据。你可以通过在对象图标之间拾取并拖动一条蓝线，来连接或断开对象。

正如你可能预料到的，并非所有类型的处理模块都适用于所有种类的数据对象。如果你用鼠标右键单击某个数据对象图标，会弹出一个菜单，显示所有可以连接到该对象的模块类型（此外，你也可以用左键、右键或中键单击图标右侧的白色小三角，或按[Ctrl]+[Space]）。关于该菜单的更多细节，请参阅Object Popup文档。选择其中一个模块，会自动创建该模块类型的一个实例，并把它连接到该数据对象。作为响应，会出现一个新图标和一条连接线。通过这种方式，你可以建立一个或多或少复杂的项目，它代表执行某项特定可视化任务所需的计算步骤，并被用于触发这些步骤。请注意，已使用过的模块会以快捷（或宏）按钮的形式出现在窗口的上部。

如果你更仔细地观察某个对象的图标，会注意到它左侧有两个小方块，一个白色一个橙色。如果你用鼠标左键（或右键、中键）单击白色方块，会弹出一个菜单，显示该对象的所有连接端口。

如果白色方块中带有”-“或”+”，你可以用鼠标左键（或右键、中键）单击它，以隐藏(“collapse”，折叠)或取消隐藏(“expand”，展开)连接到该对象的那些对象。当Project Graph View中的对象太多、难以一次全部查看时，折叠功能就很有用。被隐藏的对象将在Project > Show Object菜单中可见。

橙色方块控制该对象在各查看器中的可见性。它显示当前的查看器布局(1个查看器、2个查看器等)。单击该方块内部对应于某个特定查看器的区域，即可切换该对象在那个查看器中的可见性。当模块在该查看器中被设为不可见时，相应区域会变为灰色。如果你使用超过4个查看器，每个额外的查看器都会在对象图标上拥有自己的橙色方块。你也可以通过单击Properties Area中的可见性开关来控制某个对象的可见性。

如上所述，对于大多数对象，所需的连接会在创建时自动建立。不过，为了设置可选连接，你必须使用连接弹出菜单。例如，你可以把一个可选的标量场附加到某个Isosurface模块的Colorfield端口，以便使用Colorfield中的数值为该曲面着色。

一旦你从对象图标的连接弹出菜单中选择了某个条目，你就可以为该端口选择一个新的输入对象。为此，请单击Project Graph View中输入对象的图标。如果该连接端口可以被连接到所选对象，蓝色的连接线会变亮。无法把某个输入连接到某个端口的原因可能包括：数据类型不兼容（使用Convert Image Type更改）、输入的维度不兼容（使用Channel Works更改）、数据的网格类型不兼容（例如使用Arithmetic采样到一个规则网格上），或者该连接根本没有意义，例如把一个用于曲面的显示模块连接到一个体数据集上。

要断开某个输入对象，请单击该端口所属模块的图标。数据对象拥有一个称为Master的特殊连接端口。该端口指向某个附加到它的计算模块或编辑器。它表明该计算模块或编辑器控制着这个数据对象，即它可能会修改其内容。

每个对象都有一个关联的控制面板，其中包含用于设置或更改该对象附加参数的按钮和滑块。一旦对象被选中，即用鼠标左键单击其图标，该控制面板就会变为可见。为了选择多个对象，你可以shift-单击相应的图标，或者使用矩形选择工具选中它们（在Project Graph View背景上按住鼠标左键，然后拉出一个矩形）。

10.1.10 属性区域

Properties Area是显示所选对象用户界面的地方。通常，该界面由排列在Groups（组）和Ports（端口）中的按钮和滑块组成。端口是允许用户通过它向模块传递信息的对象。组是一个包含若干与共同主题相关的端口的对象。它们可以被折叠或展开。例如，在图10.5中，与重采样和优化选项相关的端口分别被汇集在Resampling Options和Optimizer Options组中。另外两个被折叠的组是Metric和Localizers。有些端口是高级端口，这意味着只有当Properties Area面板右上角的Advanced开关处于开启状态时它们才可见。否则，这些端口会被隐藏并设为默认值。你可以通过Properties Area左侧较深的颜色指示条来辨认高级端口。

一旦某个对象被选中，它的输入控件就会显示在Properties Area中。默认情况下，Properties Area显示在Avizo Project View的下方，但由于Properties Area面板是一个停靠部件，你可以轻松地把它移动到Avizo主窗口中你想要的位置。你可以通过单击Standard Toolbar中的Properties或在Window Menu中来快速显示/隐藏Properties Area面板。

每个对象都有一组特定的可控参数或选项。这些参数在参考手册的模块索引一节中对每个模块都有详细描述。对象（模块、数据……）还提供一个问号按钮，让你直接访问该对象的文档。

对于那些需要你显式启动其动作的模块，Apply处于活动状态（绿色）。通常，那些动作可能耗费大量时间的模块就属于这种情况，例如某些计算模块。

勾选auto-refresh复选框，可在项目发生任何更改时自动强制执行一次apply。

对象的名称显示在其控制面板的顶部，同时还有各种控制按钮。所有数据对象和显示模块，对每个3D查看器都有一个或多个橙色的查看器按钮。这些按钮控制某个对象的图形输出是否在某个特定查看器中显示。例如，如果你有两个查看器和两个Isosurface模块，你可能希望在每个查看器中显示一个Isosurface。

切片类型的显示模块（橙色的那些，例如Ortho Slice）提供一个裁剪按钮。单击该按钮会使任何其他模块的图形输出被该切片裁剪。裁剪不会影响那些几何被隐藏的模块，也不会影响在裁剪按钮被按下之后才创建的模块。

如前所述，对象或模块的特定输入控件被组织成Ports（端口）。每个端口左侧都有一个图钉按钮。如果某个端口被固定，那么即使该对象被取消选择，它仍然可见。这些端口由若干部件组成，这些部件可用于设置与各种操作相关的参数（例如，通过滑块输入一个数值、通过单选按钮设置一个状态、通过开关按钮呈现一个二元选择）。这些控制元素具有统一的布局，并被划分为若干基本类型。

基本端口类型的说明包含在用户参考手册的端口索引一节中。

标签以斜体显示的端口是特殊的，因为它们是输入连接端口。它们用于把数据对象和模块连接成一个项目，该项目代表执行某项特定可视化任务所需的计算步骤。每个连接端口都包含一个列表，列出它可能被连接到的对象，此外还有一个”NO SOURCE”项，表示它不应连接到任何对象。

在Graph View模式下，这些连接端口的显示可以通过Edit / Preferences菜单的Layout标签页开启和关闭。默认情况下它们是显示的，以帮助初学者理解Project View的架构。

在Tree View模式下，这些连接端口总是显示的，因为这是该模式下定义项目的唯一机制。当某个对象与所有其他对象完全断开连接时，它可以在树中被移动到一个合适的文件夹。例如，显示模块移到Display，计算模块移到Compute，等等。

10.1.12 查看器窗口

3D查看器在Avizo中扮演着核心角色。所有几何对象都在这里以3D空间展示。该3D查看器提供强大而快速的交互技术。它可以被视为一台虚拟相机，可以被移动到3D场景内的任意位置。鼠标左键用于借助一个虚拟轨迹球来改变观察方向。鼠标中键用于平移，而左键和中键同时按下则允许你对对象进行放大和缩小。

可以使用以下控制方式：

  • 按住鼠标左键并移动鼠标，可绕相机当前的焦点旋转相机（焦点可以通过执行一次seek操作来改变）；按住鼠标左键 + [SHIFT]可把该旋转约束在X轴或Y轴上，按住鼠标左键 + [CTRL]则约束在Z轴上。
  • 按住鼠标中键进行平移。
  • 按住鼠标左键 + 中键进行缩放/推拉，或者[CTRL] + 鼠标中键，或者[CTRL] + [SHIFT] + 鼠标左键。
  • 单击鼠标右键打开弹出菜单（更多细节参见查看器弹出菜单说明）。
  • 按[S]键，然后用鼠标左键单击某个对象，以”seek”到该位置。
  • 按[P]键，然后单击鼠标左键，以在查看器中拾取一个3D对象。相应的模块将被选中。
  • 按[Space]键以查看整个3D场景。

某些查看器小部件(viewer gadgets)可能显示在显示区域的某个角落：

  • camera trackball（相机轨迹球）：用于绕屏幕对齐的X、Y或Z轴对相机进行受约束的旋转。单击垂直的轮盘（选中时它会变红）并上下移动鼠标（同时按住鼠标左键）以绕X轴旋转。单击水平的轮盘（选中时它会变绿）并左右移动鼠标（同时按住鼠标左键）以绕Y轴旋转。单击第三个轮盘（它会变蓝）并上下移动鼠标（同时按住鼠标左键）以绕Z轴旋转。
  • 3D compass（3D罗盘）：指示当前的相机观察方向。它仅仅是一个指示器；你无法用它来控制观察方向。

Edit > Preferences > Layout对话框可用于控制查看器小部件和罗盘的可见性、自动隐藏选项以及位置。更多细节参见查看器小部件一节。

有时你需要直接在3D查看器中操纵对象。例如，Transform Editor就使用了这种被称为3D交互的技术。你可以用数据对象属性中的变换编辑器按钮来打开这个编辑器。该编辑器提供特殊的拖动器，它们可以被拾取并平移或旋转，以便指定某个数据对象的变换。在你能够与这些拖动器交互之前，你必须先把查看器切换到interaction mode（交互模式）。这是通过单击左上角的箭头按钮来完成的。如果查看器处于交互模式，鼠标光标将是一个箭头而不是手形符号。你可以使用[ESC]键在交互模式和观察模式之间快速切换。如果查看器处于交互模式，使用[Alt]键可以临时切换到观察模式。

同一时间可以有多个查看器处于活动状态。带有一个、两个或四个查看器的标准屏幕布局可以通过View菜单选择。可以使用Tcl命令viewer <n> show创建额外的查看器，其中<n>是0到15之间的整数。查看器0到3会被放置在一个公共面板窗口中，而查看器4到15会创建它们自己的顶级窗口。为了实现更具体的控制，查看器提供了一套广泛的命令集，记录在第11.5.4.1节 查看器命令选项中。

10.1.12.1 查看器工具栏说明

主查看器窗口的工具栏提供若干按钮和控件，允许你例如在观察模式与交互模式之间切换、选择某些朝向，或拍摄快照。以下描述这些控件的确切含义。

Interact：把查看器切换到交互模式。你也可以使用[ESC]键在观察模式和交互模式之间切换。

Trackball：把查看器切换到观察模式。你也可以使用[ESC]键在交互模式和观察模式之间切换。鼠标左键用于借助虚拟轨迹球改变观察方向。

Translate：与Trackball相同，只是鼠标左键用于平移（移动）。

Zoom：与Trackball相同，只是在该模式下，鼠标左键的垂直运动控制缩放。

Rotate：绕当前观察方向旋转相机。默认情况下，执行一度的顺时针旋转。如果单击时按住[SHIFT]键，则执行90度旋转。如果按住[CTRL]键，旋转将是逆时针的。

Seek：按下seek按钮，然后单击场景中的任意对象，会使该对象被移动到查看器窗口的中心。此外，相机会被定向为平行于所选点处的法线方向。也可以在查看器窗口中按[S]键来激活seek模式。
重要说明：当在某个对象上使用前向面剔除(front face culling)模式时，除非你把相机移动”穿过”前向隐藏面，否则Seek将作用于隐藏面。这个限制将在未来的Avizo版本中解决。

Home：把相机重置到home位置。

Set Home：把当前位置设为新的home位置。

View All：重新定位相机，使所有对象都变为可见。相机的朝向不会改变。

XY-、XZ-和YZ-Views：按照指定的观察方向调整相机。观察方向平行于垂直于指定坐标平面的那个坐标轴。如果按住[SHIFT]键，则使用相反的观察方向。
注意：在某些版本中，这些按钮会被地理视图朝向按钮所替代。

Geographic View Orientation：按照指定的观察方向调整相机：从上方、从下方、从西、从东、从南、从北。
注意：在某些版本中，这些按钮替代XYZ视图按钮。

Perspective/Ortho：在透视相机和正交相机之间切换。默认使用透视相机。正交相机可用于测量距离，或在3D空间中精确对齐对象。
注意：同一时间只有其中一个按钮可见，该按钮指示当前活动的相机类型。

Stereo：允许你启用或禁用立体观察，以及通过立体首选项对话框指定各种立体观察参数。

Pick：按下pick按钮，然后单击场景中的任意对象，会使相应的模块被选中。也可以在查看器窗口中按[P]键来激活拾取模式。

Measuring：按下该按钮会创建一个Measurement模块的实例，让你测量查看器中对象上的距离和角度。单击其中的向下箭头会显示一个测量工具菜单供你选择：3D Length、3D Angle、3D Annotation、3D Box、3D Circle。同一时间工具栏上只会显示其中一个按钮，即最近从查看器工具栏访问过的那个测量工具的按钮。
注意：取决于Avizo的版本，所创建的Measurement模块可能会有所不同。

Quick Probe：该按钮允许你选择在Interaction mode下可用的探测模式。默认情况下，Quick Probe是移动敏感的，即鼠标光标下的体素值和坐标会显示在进度条中。单击该按钮，你可以禁用快速探测模式，或使其变为移动敏感或单击敏感。单击敏感的行为是：如果按住[SHIFT]键并在查看器中的某个可视化上按下鼠标左键，则显示坐标和数值。
注意：如果按住[SHIFT]键，那么在查看器中除了单击进行探测之外，无法进行任何其他交互。

Display unit：该按钮指定当前所选的显示单位。单击该按钮的向下箭头会显示一个包含所有可能显示单位的菜单。
注意：只有在单位管理被激活、且显示单位可修改（即首选项选项中的”Lock display units on working units”未被勾选）时，该按钮才可见。

Snapshot：拍摄当前渲染区域的快照并保存到文件。文件名以及所期望的输出格式必须通过快照对话框输入。也可以使用查看器命令snapshot来拍摄快照。

Layout：选择查看器布局：单个视图、两个并排的查看器、两个上下堆叠的查看器，或四个查看器。

Fullscreen：选择全屏模式。在该模式下，查看器占据整个屏幕，其他窗口都不可见。要退出全屏模式，请单击鼠标右键并在弹出菜单中取消勾选Fullscreen。

Link objects visibility：在所有查看器之间链接对象的可见性。当被勾选时，意味着在一个查看器中更改某个对象的可见性（查看器掩码）会在所有查看器中改变它。

除了这些按钮之外，Avizo查看器还提供一套广泛的Tcl命令，列在第11.5.4.1节 查看器命令选项中。

10.1.12.2 查看器弹出菜单说明

所有查看器都包含一个弹出菜单，允许你配置各种选项。单击鼠标右键会打开这个弹出菜单。以下菜单选项可用：

Functions：包含一个子菜单，其中的各项分别是Home、Set Home、View All和Seek图标的快捷方式。

Viewing：在观察模式和交互模式之间切换（更多细节参见Interact和Trackball图标）。与按[ESC]键相同。

Fullscreen：Fullscreen图标的快捷方式。

Headlight：激活和停用头灯（更多细节参见Lights一节）。

Preferences：包含以下菜单项：

  • Seek to point：当被激活时，Seek工具将聚焦到被单击的那个点上，否则它将聚焦到对象的原点。
  • Auto clip planes：在每次相机移动时调整相机的近平面和远平面。
  • Automatic interactive mode：该选项可在查看器处于Interact模式时获得更好的性能。
  • Stereo：Stereo图标的快捷方式。
  • Spin animation：当启用旋转动画时，如果你在松开鼠标时鼠标正在移动，轨迹球会在之后继续旋转。默认情况下，旋转动画被禁用。
  • Rotation axes：在查看器中心显示旋转轴。

Show trackball：显示/隐藏相机轨迹球（更多细节参见查看器小部件一节）。

Show compass：显示/隐藏罗盘（更多细节参见查看器小部件一节）。

Link camera to：该菜单选项创建一条从当前查看器到你所选查看器的相机链接（在你选择该菜单选项后单击目标查看器即可）；在选择某个查看器之前按[ESC]键会中止该链接操作。当两个查看器的相机被链接时，它们会从同一个3D点、朝同一个方向观察这两个场景。下面的Unlink camera一节说明如何移除相机链接。

Unlink camera：该菜单选项通过选择要取消链接的查看器，来移除两个查看器之间的相机链接。

Show objects in extra viewer：该菜单选项允许使用相同的查看器掩码，在额外的查看器中显示当前查看器中的对象。

Object visibility：该子菜单控制查看器中对象的可见性。以下选项可用：

  • Hide All：为该查看器隐藏所有对象。
  • Show All：为该查看器显示所有对象。
  • Visible objects：用于控制当前查看器中所有显示模块可见性的子菜单。当被勾选时，意味着该模块可见。
  • Link to all viewers：在所有查看器之间链接对象的可见性。当被勾选时，意味着在一个查看器中更改某个对象的可见性会在所有查看器中改变它。
  • Same as viewer 0, Same as viewer1,…,Same as extra viewer：复制查看器i的对象可见性设置。

Identify：该菜单选项在查看器中短暂显示该查看器的标识符。

Identify all viewers：该菜单选项使每个查看器都短暂显示其查看器标识符。

10.1.18 作业对话框

Avizo中某些耗时的操作可以在批处理模式下执行。为此，Avizo提供了一个作业队列，可以在其中提交诸如四面体网格生成之类的作业。你可以通过从Avizo的Edit Menu中选择Dialogs > Jobs来检查作业队列的当前状态、启动和删除队列中的作业。这会调出Job Dialog。

某个用户当前的作业列表显示在Job Dialog的上部。对于每个作业，都会显示一段简短的描述，以及该作业被提交的时间和当前状态。作业可能处于等待执行、正在运行、已完成，或者已被终止的状态。

图 10.28：Job Dialog让你启动、停止、检查和删除批处理作业。

请注意，Avizo使用网络接口与批处理作业通信，这可能会被你的防火墙阻止。

作业目录

对于每个作业，都会创建一个临时目录，其中包含所需的输入数据、脚本、状态信息和日志文件。在Unix系统上，该目录创建在由环境变量TMPDIR所指定的位置。如果不存在这样的变量，则使用/tmp。在Windows系统上，使用默认的临时目录。通常，这将是C:/TEMP或%USERPROFILE%/AppData/Local/Temp。

控制作业队列

作业的状态可以使用作业列表上方所显示的操作按钮来操纵。为了启动作业队列，请选择第一个等待执行的作业，然后按Start按钮。请注意，同一时间只能执行一个作业。为了终止一个正在运行的作业，请在作业列表中选中它并按Kill按钮。你可以使用Delete按钮从作业队列中删除一个作业。删除作业时，临时作业目录也会被移除。

关于作业的信息

一旦你在作业队列中选中某个作业，关于它的更详细信息就会显示在对话框窗口的下部，特别是该作业的状态、临时作业目录、提交时间、作业启动的时间、运行时间，以及待执行命令的名称。正在运行作业的任何控制台输出，都会被重定向到位于临时作业目录中的一个日志文件。一旦这样的日志文件存在且大小非零，你就可以通过按下View output按钮来检查它。

网络问题

作业成功和失败的通知要求Avizo打开一个TCP/IP端口。取决于你的网络配置，你可能无法接收这些通知。在这些情况下，请联系你的系统管理员，或者如果你有足够的权限，请更改防火墙设置。

命令

  • job submit cmd info [tmpdir]：向作业队列提交一个新作业。cmd指定待执行的命令。info指定在Job Dialog中显示的信息字符串。tmpdir指定临时作业目录。如果省略该参数，则由Avizo自己创建一个临时作业目录。无论哪种情况，当作业从作业队列中被移除时，该目录都会被自动删除。示例：job submit "clock.exe" "Test job"
  • job run：启动作业队列中第一个等待执行的作业。当一个作业完成时，队列中下一个作业的执行会自动开始，因此队列中的所有作业都将通过job run被连续执行。

10.1.20 快照对话框

Snapshot Dialog提供查看器快照功能的用户界面。你可以通过单击Viewer window工具栏中的相机图标获得该对话框。

  • Output：指定输出设备。选择to file时，所抓取的图像会被保存到文件；选择to printer时，图像会被直接发送到打印机；选择to clipboard时，它会被发送到剪贴板。在to printer模式下，你必须先按下Configure printer按钮来选择并配置一台打印机。此外，你可以输入任意文本字符串，它将作为注释文本被打印在快照图像下方。

  • Offscreen：让你抓取比实际屏幕尺寸更大的图像。当勾选该选项时，输出尺寸可以在width和height文本字段中指定。如果其中某个离屏尺寸大于4096，则会自动使用平铺(tiles)算法。请注意，离屏选项会覆盖平铺选项。

图 10.29：Snapshot Dialog允许你保存或打印Viewer window的内容。

  • Render tiles：使用该选项可渲染几乎无限分辨率的快照（例如用于高质量打印输出）。在该模式下，场景被划分为 n x m 个图块，其中n和m可以输入到相邻的文本字段中。然后相机位置会被设置为使每个图块填满当前查看器，并拍摄一张快照。最后，这些图块会在内部被合并为单张图像，并发送到Output端口所指定的设备。请注意，在使用平铺进行快照时，[注释—颜色图显示—绘图查看器—电子表格查看器—比例尺] 会改变它们的大小。

  • Antialias：使用该选项可在启用抗锯齿的情况下渲染快照。在该模式下，抗锯齿是通过先进行平铺渲染、随后再降采样来实现的。Antialias因子决定抗锯齿的程度。

  • Capture all viewers：该选项取消Render tiles选项，并允许在使用多个查看器时为所有查看器创建一张快照。

  • Filename：如果设置了to file选项，让你指定文件名。Browse按钮允许你浏览到文件系统中所期望的位置。

  • Format：format选项让你选择要为文件输出产生的文件格式。支持以下格式：TIFF(.tif、.tiff)、SGI(.rgb、.sgi、.bw)、JPG(.jpg、.jpeg)、PPM(.pgm、.ppm)、BMP(.bmp)、PNG(.png)、DCM(.dcm)、Encapsulated PostScript(.eps)、JPEG2000(.jp2)和PDF(.pdf)。此外，该端口还提供三个单选按钮，用于在grayscale、rgb和rgb alpha类型的光栅图像之间选择。如果设置了rgb alpha选项，所产生的图像会把查看器背景指派给alpha通道。该选项对于不支持alpha通道的文件格式不可用。

  • Auto-save project：使用该选项可在保存快照之外同时保存项目。如果勾选该选项，项目将被保存在与由filename所指定快照相同的位置，并以.hx结尾（即snapshot.jpg.hx）。

警告：无法生成大于2GB的快照。图片大小取决于：

  • 如果选择了Offscreen，则取决于Width、Height和Antialias
  • 否则取决于Render tiles x、Render tiles y和Antialias

如果快照大小超过2GB，会显示一个警告工具提示，导致更大尺寸的那个值不会被确认。

命令

snapshot [options] [filename] [filename2 (仅用于立体模式)]

选项：

  • -stereo：如果使用该选项，则创建立体模式图像。在这种情况下，filename2文件可用于指定立体图像的第二张图像存储在哪里。
  • -alpha：如果使用该选项，创建的快照图像带有透明背景。
  • -tiled nx ny：如果使用该选项，则使用平铺渲染，水平方向图块数为nx，垂直方向图块数为ny。
  • -offscreen [width height]：如果使用该选项，则使用离屏渲染，其中width和height是所渲染图像的宽度和高度。

10.2.1 类结构

在本节中，我们稍微详细地讨论Avizo的面向对象设计。你已经知道，数据对象（例如灰度图像数据或矢量场集）会作为独立的图标出现在Project View中。你也已经知道，有一些显示模块可用于可视化这些数据对象。虽然某些模块可以连接到许多不同的数据对象（例如Bounding Box模块），另一些则不行（例如Ortho Slice模块）。后者只能连接到体素数据，或连接到体素网格上的标量场。原因在于，二者在内部都被表示为一个具有均匀笛卡尔坐标的标量场。因此，同样的可视化方法可以应用于两者。另一方面，例如某个感兴趣对象的体四面体网格模型，通常看起来完全不同。但由于它同样是一个3D数据对象，同一个Bounding Box模块也可以连接到它。

总之，Avizo的数据对象可能被认为属于不同类型，但就数学结构、观察和其他处理模块的适用性以及编程接口设计而言，它们有许多共同属性。遵循面向对象设计的原则，Avizo的数据类型被组织在类层次结构中，其中共同属性被归属于”更高层”的类，并被”派生”类所继承——某个类的子类通常被称为派生类。从概念上讲，Avizo中出现的每个对象都是某个类的实例，也是该类在层次结构中每个前驱类的实例。这些类及其层次结构是在Avizo内部定义的。作为用户，你通常只需处理类的实例。例如，有一个名为”HxObject”的类，它有”HxData”和”HxModule”两个子类。”HxData”包含与那些用于建模感兴趣对象的数据对象相关联的数据类型，例如体四面体网格或曲面。”HxModule”包含被指派给显示和其他处理模块的数据类型，这同样符合面向对象设计的原则。这就是为什么Avizo的数据对象和处理模块通常被称为”对象”。

Avizo中还有一些并非派生自”HxObject”的类，它们构成其他数据类型，并且存在若干独立的类层次结构。例如，有一个名为”HxPort”的类，所有支持界面控制元素操作和显示的类都派生自它（参见用户指南索引部分的Properties Area和List of Ports一节）。

单个类层次结构通常被描绘为一棵倒置的树，即根在顶部。因此，data类树就是这样一棵树：关于某个处理模块适用于哪个数据对象的信息被挂接在它上面。它的类反映了Avizo所支持对象模型的数学结构。例如，标量场和矢量场就是这样的结构，它们派生自一个共同的”field”类，该类表示一个映射$R^3 \rightarrow R^n$。从这个基类派生子类需要为$n$指定一个值。

同时，定义在笛卡尔网格上的场与定义在四面体网格上的场被区分开来，即这种区分是分类方案的一部分，它在data类子树中产生了分支。你将在本章下一节中了解更多关于data类层次结构的内容。在第二节中，我们讨论一些常用于各种可视化任务的数据类型如何归入其中。

在内部，所有类名都以前缀Hx开头。不过，除非你想使用命令外壳来创建对象，否则你不必记住这些名称。例如，边界框通常是通过从待可视化数据对象的弹出菜单中选择Bounding Box项来创建的，但你也可以通过在命令窗口中键入create HxBoundingBox来创建它。

10.2.2 标量场与矢量场

Avizo中最重要的场是三维的场。这些场定义在某个域$\subseteq R^3$上。场可以在其域内的任意点被求值。如果该场定义在一个离散网格上，这通常涉及某种插值。

10.2.2.1 标量场

3D标量场是一个映射$R^3 \rightarrow R$。Avizo中所有3D标量场的基类是HxScalarField3。各种子类代表定义标量场的不同方式。针对它们有许多可视化方法，例如切割平面上的伪彩色、等值面化或体绘制。不过，Avizo中许多可视化模块依赖于某种特殊的场表示。因此，它们只能作用于一般标量场的子类。每当某个给定几何要被伪彩色着色时，任何种类的标量场都可以被使用（参见Color Wash、Tetra Grid View、Isosurface）。

类HxTetraScalarField3表示一个定义在四面体网格上的场。在每个网格顶点上，都定义了一个标量值，例如温度。与四面体内部各点相关联的值，是由四个顶点值通过线性插值获得的。该类不提供网格本身的副本，而是提供一个对该网格的引用。这在Project View中由一条连接网格图标和场图标的线来指示。因此，如果网格本身尚未存在，定义在四面体网格上的场就无法被加载到系统中。

类HxRegScalarField3表示一个定义在规则笛卡尔网格上的场。这样的网格被组织为一个三维节点数组。在最简单的情况下，这些节点是轴对齐且间距相等的。这样一个均匀网格的坐标，可以从一个简单的边界框获得，该边界框包含原点矢量以及所有方向上的增量。堆叠坐标是另一个例子。这里，相邻切片之间在z方向上的间距可能不同。无论哪种情况，六面体网格单元内部的标量值都是使用八个顶点值通过三线性插值获得的。虽然Ortho Slice模块只能用于可视化具有均匀或堆叠坐标的标量场，但诸如Slice或Isosurface之类的其他模块可用于所有具有规则坐标的标量场。

标量场的又一个例子是类HxAnnaScalarField3。它表示一个解析定义的标量场。要创建这样一个场，请从Avizo主窗口的Project > Create Object...菜单中选择Images And Fields / Analytic Scalar Field。你必须指定一个数学表达式，用于在每个被请求的位置对该场求值。最多可以有三个其他场被连接到该对象。它们可以被组合成一个新的标量场，即使它们定义在不同的网格上。

10.2.2.2 矢量场

与标量场一样，Avizo提供了许多矢量场类，它们派生自基类HxVectorField3和HxComplexVectorField3。普通矢量场在每个位置返回一个三分量矢量，而复矢量场返回一个六分量矢量。复矢量场用于按某些应用的要求编码稳态电磁波模式。通常，复矢量场是通过把它们投影到使用不同相位偏移的实数空间中来可视化的。Vectors Slice模块甚至允许你为相位偏移制作动画。通过这种方式，可以获得对振荡波模式的良好印象。

10.2.3 坐标与网格

Avizo在其Avizo Lite Edition中目前支持两种重要的网格类型，即具有六面体结构的网格（规则网格）和非结构四面体网格。

在Avizo XWind Extension中，支持非结构混合网格。关于Avizo XWind Extension中非结构网格的更多信息，请参阅第13章 Avizo XWind Extension用户指南或Unstructured Model文档。

其他类型的网格（例如块结构网格）将在Avizo的未来版本中添加。

10.2.3.1 规则网格

规则网格由一个三维节点数组构成。每个节点都可以由一个索引三元组(i,j,k)来寻址。规则网格还根据所使用坐标的种类被进一步区分。最简单的情况包含uniform（均匀）坐标，其中所有单元都被假定为矩形且轴对齐。此外，网格间距沿每个轴都是恒定的。具有stacked（堆叠）坐标的网格可以被想象为一叠均匀的2D切片。不过，相邻切片之间在z方向上的距离可能不同。在rectilinear（直线）坐标的情况下，单元仍然与坐标轴对齐，但网格间距可能逐单元变化。而在curvilinear（曲线）坐标的情况下，网格的每个节点都可以有任意坐标。具有曲线坐标的网格常用于流体动力学，因为它们结构简单，却仍允许对像转子叶片或翼型这样的复杂形状进行精确建模。

10.2.3.2 四面体网格

Tetra Grid表示由许多四面体构成的体网格。此类网格通常可用于执行有限元仿真，例如E场仿真。

Tetra Grid中维护着相当数量的信息。对于每个顶点，存储一个3D坐标矢量。对于每个四面体，存储其四个顶点的索引，以及一个指示该四面体所属区段(segment)的编号——该区段由分割过程获得。除了这些基本信息之外，为了让网格能被快速显示，还存储了许多附加变量。特别是，所有三角形或面都被单独存储，每个四面体带有六个面索引。此外，对于每个面，都存储指向它所属的两个四面体的指针。通过这种方式可以高效地获得邻域信息。

当使用有限元方法进行仿真时，网格的边需要被显式存储，因为使用了矢量元素或Whitney元素。这些元素及其相应的系数是按边定义的。当某个网格被选中时，会显示关于其顶点、边、面和四面体数量的信息。

10.2.4 曲面数据

Avizo提供了一个专用数据类来表示三角曲面，称为Surface。该类在用户指南的索引部分有更详细的说明。目前，我们只提到该类维护连通性信息，并且它既可以表示流形拓扑，也可以表示非流形拓扑。

该曲面类提供了一套丰富的Tcl命令。它是一个很好的Avizo数据类示例——不只是简单地存储信息，而是允许用户通过专用方法和接口来查询和操作数据。

10.2.5 顶点集

数据抽象和继承的另一个例子是Vertex Set类。Avizo中许多数据对象都派生自这个类，例如地标集、分子、曲面或四面体网格。所有这些对象都提供一个带x、y、z坐标的点列表。其他需要点列表作为输入的模块只需访问Vertex Set基类，而不必知道该数据对象的实际类型。

一个作用于Vertex Set对象的通用模块示例是Vertex View模块。该模块允许你通过在每个点处绘制圆点或小球来可视化顶点位置。

10.2.6 变换

Avizo中的数据对象可以使用任意仿射变换来修改。例如，这使得把两个不同的数据对象对齐、以便它们大致相互匹配成为可能。在内部，仿射变换由一个4x4变换矩阵表示。特别地，一个均匀标量场即使被旋转或剪切，它仍然是一个均匀标量场。诸如Ortho Slice之类的显示模块仍然可以利用均匀场的简单结构。可能存在的变换会被自动应用到3D查看器中所显示的任何几何上。

为了交互式地操纵变换矩阵，请使用Transform Editor（文档包含在用户指南的索引部分中）。

在保存已变换的数据集时要小心！大多数文件格式不允许你存储仿射变换。在这种情况下，你必须把当前变换应用到数据上。这可以使用applyTransform Tcl命令来完成。在顶点集对象的情况下，该变换会被应用到所有顶点上。旧坐标被新坐标替换，之后变换矩阵被重置为单位矩阵。变换一旦被应用到某个数据集上，就无法被轻易撤销。

如果变换被应用到均匀场（例如3D图像数据）上，坐标结构不会改变，即该场仍然是均匀的。取而代之的是，数据值会被重采样，即在最终规则网格的每个顶点上对变换后的场进行求值。所得网格的边界框会被修改，使其完全包围变换后的原始框。

10.2.7 数据参数

可以为任何数据对象定义任意数量的附加参数或属性。数据参数可以使用Data Parameter Editor交互式地添加、删除或编辑。参数很有用，例如可用于存储某次仿真或某个实验的某些参数。通过这种方式，可以追溯某个数据对象的历史。

有一些参数会被若干Avizo模块所解释。这些参数的含义总结在以下列表中：

  • Colormap name

    这指定用于可视化该数据的默认颜色图的名称。某些模块会自动在Project View中搜索这个颜色图，并例如把它用于伪彩色着色。

  • DataWindow minVal maxVal

    这指示用于可视化该数据的首选数据范围。Ortho Slice模块会自动把低于minVal的值映射为黑色，把高于maxVal的值映射为白色。

  • LoadCmd cmd

    该参数通常在读取某个数据对象时由导入过滤器设置。它在把当前项目保存到文件时被使用，并允许该对象被自动恢复。仅供内部使用。

请注意，有许多文件格式不允许存储参数。因此，当你以这样的格式导出数据集时，信息可能会丢失。如有疑问，请使用专门的Avizo Format。

10.2.8 阴影

实时阴影投射通过Preferences Dialog的Rendering标签页启用（可通过Standard Toolbar中的Preferences按钮或Edit > Preferences菜单项访问）。

一旦启用，大多数显示模块都可以投射或接收阴影。
有若干不同模式可用，通过单击某个显示模块的阴影图标可以在它们之间切换：

  • No Shadows：所显示的形状既不投射也不接收阴影
  • Cast Shadows：所显示的形状只投射阴影
  • Receive shadows：所显示的形状只接收阴影
  • Cast & Receive shadows：所显示的形状既投射也接收阴影

限制：

你的显卡至少必须支持Multi-Texture和Texture Environment Combine这两个OpenGL®扩展。否则，不会计算任何阴影。这些扩展现在已是OpenGL®1.3及更高版本中的标准。

如果可用，会使用Shadow和Depth Texture OpenGL®扩展（OpenGL®1.4中的标准），它们通常能改善性能。

如果你把场景放大到非常近，可能会出现一些锯齿伪影。此时你可以在Preferences Dialog中提高质量。

透明对象的处理方式取决于透明度类型：

  • Screen door：完全兼容
  • Add, Blend：透明对象会投射阴影并被阴影覆盖，但阴影强度不依赖于透明度值（对完全透明的形状和不透明的形状显示相同的阴影）。
  • All other modes：与阴影不兼容。

阴影可能影响性能，并且只有某些显示模块/模式（例如Volume Rendering）才完全支持它。设置环境变量AVIZO_FORCE_SHADOW_MAP可以启用一种限制较少的阴影模式（即更多模块支持它，但Volume Rendering不支持）。

10.2.9.1 概述

当在Avizo中激活单位管理时，你将能够：

  • 为每个空间数据对象关联一个坐标单位，或直接从数据文件中取回它（取决于读取器和文件格式），或使用Units Editor手动设置它。
  • 用相同的坐标单位（例如米）存储所有已加载空间数据对象的坐标值。Avizo中所存储并在内部使用的坐标单位称为工作单位(working units)。工作单位可以由用户指定，也可以自动确定（参见自动确定或手动设置工作坐标单位）。
  • 在Avizo用户界面中以你想要的坐标单位显示与坐标相关的信息（例如边界框、长度等）。
    用于在Avizo用户界面中显示数值的单位称为显示单位(display units)。

要了解如何在Avizo中激活/停用单位管理，你可以参阅以下一节：在Avizo中激活/停用单位管理。

10.2.9.2 如何为空间数据对象关联坐标单位

当Avizo中的单位管理被激活时，每个空间数据对象都会被指派一个坐标单位。
这可以通过2种不同的方式完成：

  • 通过用于加载数据的读取器
  • 或者通过一个专门的Units Editor

在大多数可能的情况下，Avizo读取器会尝试直接从数据文件所存储的信息中提取坐标单位。例如，Avizo或MCAD读取器（如IGES）就是这种情况。

如果读取器无法确定坐标单位（信息缺失或该文件格式不支持），则将通过Units Editor指定它。该编辑器在数据加载时启动，并且在数据被注册到Project View之后，也可以像其他编辑器一样被访问。

一旦某个坐标单位被指派给该空间数据对象，它的坐标值就可能被转换。如果为该数据所指定的坐标单位与Avizo内部用于存储所有空间数据对象坐标值的单位（即所谓的工作单位）不同，就会发生这种情况。在这种情况下，坐标值将从所指定的坐标单位转换为工作单位。

注意：
手动为某个空间数据对象设置坐标单位（通过该编辑器）会把该对象标记为已修改。事实上，这意味着该数据的原始文件格式不支持坐标单位信息。在为它关联了一个坐标单位之后，该数据必须被保存到一个能够支持这类信息的文件格式中。为方便起见，你可以轻松地把数据保存为Avizo data文件格式，它会在Parameters一节中保存坐标单位，并且可用于存储许多不同的数据对象。

关于与某个空间数据相关联的坐标单位的信息，可以在若干位置访问到：

  • 在Units Editor中，在数据被加载之后，你可以在其中查看和修改某个空间数据的原始坐标单位（即在数据加载时所指定的那个）。
  • 在该空间数据的Parameter Editor中，坐标单位被指定在一个Units束(bundle)之下。事实上，在这个束之下显示了2项信息：
    • 该空间数据当前（工作）坐标单位，位于Coordinates参数中（即坐标当前在内存中所使用的存储单位），
    • 该空间数据所存储的原始坐标单位，位于OriginalCoordinates参数中（即在数据加载时通过Units Editor指定、或之后被编辑过的那个）。

10.2.9.3 如何修改用于显示信息的坐标单位

即使用于在内部存储空间数据对象坐标的坐标单位（即所谓的工作单位）是固定的，在产品用户界面中所显示的与坐标信息相关的数值，也可以用任何坐标单位来表示。

例如，你可以加载一个坐标以米（即工作单位）存储的空间数据对象，为它连接一个Bounding Box模块，并自由修改用于在该模块信息标签中显示各角点坐标的坐标单位（即所谓的显示单位）（例如选择毫米）。

在这种情况下，所显示的坐标值将从工作单位（坐标值在内部以此存储）转换为显示单位（这些值在Avizo用户界面中以此显示）。

要指定用户界面中显示坐标值所使用的坐标单位：

  • 启动Preferences对话框（菜单Edit > Preferences…）
  • 选择Units标签页
  • 选择Display units标签页
  • 在Spatial information部分中，为坐标信息选择你想要的显示单位

修改该显示单位最快捷的方式，可以在主查看器工具栏上Measure按钮与snapshot按钮之间访问到（参见查看器工具栏说明）。

如果”Lock display units on working units”选项未被勾选，则Display unit按钮处于启用状态。通过这个按钮，你不仅可以为活动查看器、而且可以为Avizo中所显示的所有单位选择你想要的坐标信息显示单位。

这些选项如下：

  • 在加载空间数据对象时激活/停用单位编辑器对话框
  • 自动确定或手动设置工作坐标单位
  • 把显示坐标单位锁定到工作单位上

  • 选择Units标签页

在Avizo中激活/停用单位管理

为了与Avizo的旧版本兼容，你并非必须在空间数据对象中使用/设置单位信息，因此可以在整个产品中停用单位管理。在这种情况下，空间数据对象将不包含任何单位信息，也不会执行与单位相关的转换：Avizo将像其以前的版本一样工作，与你所习惯的方式相同。

要在整个产品中激活/停用单位管理：

  • 在Unit management部分中，选择None以停用单位管理，或选择Spatial information以激活它并使用坐标与角度单位信息

自动确定或手动设置工作坐标单位

当单位管理被激活时，如果你加载的数据其坐标单位与Avizo内部用于存储坐标值的工作单位不同，就可能发生某些单位转换。

为了尽可能限制这些转换，我们建议你让Avizo自动确定工作坐标单位。

在这种情况下，当空间数据被加载时，工作坐标单位会被自动设置为该数据的单位。

如你所理解的，这种行为避免了对第一个被加载空间数据对象的坐标单位进行转换；但如果后续加载的空间数据不具有相同的坐标单位，转换仍然会发生。相比之下，如果你只加载具有相同坐标单位（即等于当前工作单位）的数据，就不会进行任何转换。

当然，你可以自由地激活/停用这种行为。如果你停用它，就可以自行指定Avizo将用于存储坐标值的工作坐标单位。在这种情况下，请特别注意单位转换，尤其是在加载数据时。

注意：
如果空间数据已经被加载，你将无法选择另一个工作坐标单位：只有当Project View中不包含任何空间数据时，才可能选择自定义的工作坐标单位。

要自动确定工作坐标单位：

  • 选择Options标签页
  • 开启/关闭Automatically determine working units复选框

要指定自定义的工作单位：

  • 选择Working units标签页
  • 在Spatial information部分中，为坐标或角度信息选择你想要的工作单位

把显示坐标单位锁定到工作单位上

在某些情况下，始终以与内部存储这些坐标值所用单位相同的单位、在Avizo用户界面中显示与坐标值相关的信息，可能会很有意思。

这种行为可确保界面组件中所显示的数值与Avizo内部所操作的数值相同。

要把显示坐标单位锁定到工作单位上：

  • 选择Options标签页
  • 开启/关闭Lock display units on working units复选框

在加载空间数据对象时激活/停用单位编辑器对话框

如前所述，当单位管理被激活时，某些读取器可以启动一个专门的对话框，用于指定所加载空间数据的坐标单位。

只有当读取器未能从数据文件所存储的信息中自动取回坐标单位时，该对话框才会被启动。

请注意，你可以选择阻止该对话框被显示。在这种情况下，所加载的空间数据对象将被假定具有首选项中所指定的默认坐标单位。

注意：
即使你选择在数据加载时不自动显示该对话框，你仍然有可能借助在Project View中选中该空间数据对象时可用的单位编辑器来指定坐标单位。

要在加载空间数据对象时激活单位编辑器对话框：

  • 选择Options标签页
  • 前往When the coordinate units are unknown at data loading分组框
  • 开启Show Units Editor dialog复选框

要在加载空间数据对象时停用单位编辑器对话框：

  • 选择Options标签页
  • 前往When the coordinate units are unknown at data loading分组框
  • 在Use XXX as default coordinate units中选择你偏好的坐标单位
  • 如果相关联的复选框未被开启，请勾选它。

10.2.10 Avizo中的自动显示

本节描述配置和使用Avizo中自动显示功能的方式。该功能的目的是：当有新数据被添加到Avizo中时，自动连接一个显示模块。例如，你可以指定一个Ortho Slice被自动连接到所有新图像，并且一个Surface View被连接到所有新曲面。

10.2.10.1 在首选项中管理和配置自动显示

有若干与自动显示相关的选项可用，允许你定制在Avizo中使用它的方式。这些选项如下：

  • 在Avizo中激活/停用自动显示
  • 为已加载数据和已计算数据选择自动显示的行为
  • 选择数据类型与所关联显示模块之间的关联关系

要访问自动显示首选项：

  • 启动Preferences对话框（菜单Edit > Preferences…）
  • 选择Auto-Display标签页

该首选项标签页的内容类似于下图：

在Avizo中激活/停用自动显示

第一个可用选项是一个全局选项，它允许你启用（如果你勾选该框）或禁用（如果你取消勾选该框）Avizo中的自动显示机制。

为自动显示机制选择功能模式

有三种功能模式可用，允许你使自动显示行为适应你的工作习惯。

你可以为以下对象激活自动显示：

  • 仅已加载的数据，即已计算的数据永远不会被自动连接到显示模块

10.2.11 工作间概念

除了可视化模块之外，该用户界面还使应用领域之间的切换更容易、更快速。借助用户友好的”工作间”(workroom)概念，若干专用组件可作为独立的应用程序被访问，它们被组装到通用的Avizo平台中。每个组件都提供其自身特定的界面、专用工具和可视化选项。由于不同组件之间的切换是通过一个简单的工具栏进行的，用户可以使用各工作间中的专用工具来探索和处理复杂的数据集，同时在通用框架中保持清晰的总览。要访问某个工作间，主窗口的上部提供了一个工具栏。

以下组件目前是工作间：

  • Start Page：开始一个项目、加载数据、了解Avizo。
  • Project View：打开数据、连接模块、打开和保存项目。按”Home”键可直接打开该工作间。
  • Segmentation Editor：交互式地分割3D图像数据。
  • Filament Editor：自动且交互式地提取、分析和量化3D图像数据中的丝状结构（参见教程：Filament Editor）。
  • Animation Director：从当前项目创建动画并录制影片文件（参见教程：The Animation Director）。
  • Metrology：测试计划创建、几何拟合、视图对齐和零件尺寸标注。
  • Recipes：配方创建、可定制的工作流自动化。
  • Reporting：报告生成、把分析导出为HTML和PDF。
